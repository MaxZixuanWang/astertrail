# 追星人 · Astertrail 网页版

**中文** | [English](README.en.md)

手机上的星空指南。默认星图，一键进入后置相机实景 AR；无需微信小程序或应用商店。

**在线使用：[追星人 · Astertrail](https://maxzixuanwang.github.io/astertrail/)**

## 在手机上使用

1. 用 Safari（iPhone）或 Chrome（Android）打开网站的 **HTTPS 地址**。
2. 设置观测地点：允许定位，或直接填写经纬度。示例地点不会自动当成你的实际位置。
3. 点击搜索框浏览全部 5,180 个目标，或输入星名、M31 等编号。中文按拼音、英文按名称排序；列表每次最多渲染 60 行。
4. 点击“开始 AR 寻星”，允许方向与相机访问。先稍微放平手机，再把手机背面对准天空。
5. 跟随箭头转动手机：红色在视场外，绿色在视场内；中心 1° 内保持片刻会出现画面和声音提示。支持的 Android 浏览器还会震动。

右侧缩放条上拉放大、下拉缩小。也可以在“设置”打开“手机随动”，只看星图。无方向传感器的电脑仍能拖动、滚轮缩放；手机星图支持双指缩放。

## 添加到主屏幕与离线

- iPhone：Safari → 分享 → 添加到主屏幕；若出现“作为网页 App 打开”，保持开启。
- Android：Chrome 菜单 → 安装应用 / 添加到主屏幕。支持安装提示时，“设置”也会显示安装按钮。
- “设置”显示“离线星图已就绪”后，星表、搜索、计算、头像和音效已经缓存。浏览器可能主动清理缓存；定位能否离线成功取决于设备。
- 发现新版本时，“设置”出现更新按钮。使用中不会突然刷新；返回星图后可主动更新。

## 方向与相机

- 使用后置相机、浏览器方向传感器；不识别相机画面中的恒星。AR 在 1× 时采用近似 70° 垂直视场，适合辅助找方向。
- 星图放大后切到 AR 会保留倍率，相机画面与星图同步数码放大。AR 最小为 1×，避免显示相机拍不到的范围；从 0.5× 等广角星图进入时会提示自动调整到 1×，返回星图恢复原倍率。数码放大不增加相机细节，实际视角仍因设备而异。
- Android 优先使用绝对方向，iPhone 用罗盘建立方向参考。罗盘近似磁北；未加磁偏角模型，精度不保证达到 1°。
- 没有绝对方向时会提示校准：借助已知方向或系统指南针，让手机后置相机朝正北，再点“手机背面已朝正北”。不会把相对方向自动当成北。
- 已在真实天空中认出所选天体后，可对准它并在设置里校准。不要仅根据屏幕箭头执行该校准。
- 切到后台或离开页面，会停止相机、方向监听、声音和绘图；回来后点击按钮重新开始。
- 相机或方向权限被拒绝，可继续拖动星图，并在浏览器网站权限设置中重新允许。
- iPhone 浏览器没有网页震动支持，保留画面和音效。静音模式、音量和浏览器音频策略可能影响提示音。

## 隐私

位置、偏好存放于本机浏览器，用于本机计算；相机画面不录制、不上传。应用本身没有账户、广告、分析统计或业务后台。托管网站服务仍可能记录普通网页访问日志。系统定位服务如何获取位置由设备和浏览器决定。
